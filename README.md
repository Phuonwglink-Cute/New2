# HieuDev Blue Black Premium V1.0

A single-page portfolio inspired by the layout of the referenced site, redesigned in a blue-black premium style.

## Features
- Hero / About / Skills / Projects / Gallery / Support / Contact
- Glassmorphism UI
- Smooth scrolling
- Loading screen
- Responsive on mobile / tablet / desktop
- Gallery lightbox

## Files
- index.html
- style.css
- script.js
- assets/
  - avatar.svg
  - cover.svg
  - qr.svg
  - gallery/*.svg

## Notes
This build uses self-contained SVG assets so it works without external dependencies.
